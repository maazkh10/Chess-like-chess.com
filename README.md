# ♟️ MERN Chess Game

A real-time multiplayer Chess application built using the **MERN Stack** with **Socket.IO** for live gameplay communication.

This project allows two players to connect and play chess in real time with smooth move synchronization, interactive UI, and full-stack architecture.

---

## 🚀 Features

- ♟️ Real-time multiplayer chess gameplay
- 🔌 Live communication using Socket.IO
- 👥 Two-player room system
- 🎨 Interactive chessboard UI
- ⚡ Instant move synchronization
- 🔄 Turn-based gameplay
- 📱 Responsive frontend design
- 🌐 MERN Stack architecture
- 🧠 Chess move validation
- 🔒 Backend API integration
